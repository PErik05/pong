Klasszikus Pong játék Python (`pygame-ce`) nyelven megvalósítva, kétjátékos móddal és három nehézségi szintű szabályalapú gépi ellenféllel.

## Funkciók
- **Ember vs. Ember** játékmód (`W`/`S` és `Fel`/`Le` nyilak)
- **Ember vs. AI** játékmód választható nehézséggel (**Könnyű**, **Közepes**, **Nehéz**)
- Objektumorientált, moduláris felépítés

## Telepítés és futtatás
```bash
python -m pip install -r requirements.txt
python main.py
